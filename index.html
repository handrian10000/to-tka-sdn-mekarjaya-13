Rekapitulasi Nilai Otomatis (Matematika & Bahasa Indonesia) & Koneksi Google Drive

Koneksi Otomatis ke Google Drive / Google Sheets Guru

Agar nilai siswa dari HP/Laptop mana pun langsung masuk ke Google Drive Anda secara real-time, tempelkan URL Web App Google Apps Script di bawah ini.

Panduan Google Apps Script (Diperbarui untuk Penyimpanan Otomatis)
  1. Buka Google Drive Anda → Buat Google Spreadsheet baru bernama Rekap Nilai TKA SDN Mekarjaya 13.
  2. Pastikan baris pertama (Header) kolom A sampai J berturut-turut berisi:
    Timestamp | Nama | Kelas | Absen | Paket | Nilai | Benar | Total | Status | Record ID
  3. Klik menu Ekstensi (Extensions) → Apps Script.
  4. Hapus kode lama, lalu tempel kode yang disempurnakan di bawah ini: 
    function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    // Pastikan header tertulis jika kosong
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(["Timestamp", "Nama", "Kelas", "Absen", "Paket", "Nilai", "Benar", "Total", "Status", "Record ID"]);
    }
    
    sheet.appendRow([
      data.timestamp || new Date().toLocaleString('id-ID'),
      data.name || "-",
      data.class || "-",
      data.number || "-",
      data.package || "Paket 1",
      data.score || 0,
      data.correct || 0,
      data.total || 30,
      "Tersimpan Otomatis",
      data.recordId || ("REC-" + Date.now())
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({status: "success", message: "Data tersimpan"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({status: "error", message: error.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function doGet(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var rows = sheet.getDataRange().getValues();
    return ContentService.createTextOutput(JSON.stringify(rows))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify([]))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
  5. Klik Terapkan (Deploy) → Deployment Baru (New Deployment) → Pilih jenis Web App.
  6. Atur deskripsi bebas, Execute as: Me (Saya), dan Who has access: Anyone (Siapa saja).
  7. Salin URL Web App yang dihasilkan dan tempel ke kolom di atas.
